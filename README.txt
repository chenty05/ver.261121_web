櫥窗裡的你｜建置檔說明
==================================================

作品名稱：櫥窗裡的你
作者：（請填寫）
類型：iPad 互動網頁（人格測驗 → 裝飾蛋糕 → 回饋回顧）
設計尺寸：iPad Air 13 吋橫向（2360 × 1640 px）


一、線上體驗（建議）
--------------------------------------------------
網址：https://chenty05.github.io/ver.261024_web/

・請使用 iPad 橫向開啟，建議用 Safari 的「分享 → 加入主畫面」，
  再從主畫面圖示打開，即可全螢幕、無網址列。
・電腦也可以用 Chrome / Safari 開啟，畫面會自動縮放置中。
・網址最後加上「#cake」會略過人格測驗，直接進入裝飾蛋糕。
  例：https://chenty05.github.io/ver.261024_web/#cake
・第一次點擊畫面後會開始播放背景音樂，請開啟聲音並關閉靜音模式。


二、在自己的電腦上執行
--------------------------------------------------
本作品為純前端靜態網頁（HTML / CSS / JavaScript），不需要安裝或編譯。
但瀏覽器限制直接雙擊開啟本機檔案時的部分功能（例如按鈕音效），
因此請用以下任一方式開啟：

方法 A：上傳到任何靜態網站空間
  將本資料夾內所有檔案上傳到 GitHub Pages、Netlify 等，開啟網址即可。

方法 B：用本機伺服器開啟（Mac / Windows 皆可）
  1. 打開終端機（Terminal），進入本資料夾：
       cd 本資料夾的路徑
  2. 輸入以下指令（需已安裝 Python 3）：
       python3 -m http.server 8000
  3. 用瀏覽器開啟：http://localhost:8000

方法 C：使用 VS Code 的「Live Server」外掛，對 index.html 按右鍵 →
  「Open with Live Server」。


三、檔案結構
--------------------------------------------------
index.html     主程式（版面、互動、動畫全部在這個檔案裡）
a/             裝飾蛋糕與回顧畫面使用的圖片、字型、音樂、音效
  a/rv/        回顧（畫面一～七）使用的背景與圖示
q/             人格測驗使用的題目畫面
  q/res/       人格測驗結果頁使用的圖片
README.txt     本說明檔

請保持資料夾結構不變，index.html 必須與 a、q 資料夾放在同一層。


四、體驗流程
--------------------------------------------------
1. 開場：點按店門進入。
2. 人格測驗：共五題，選擇答案後按「下一題」，最後得到五種人格之一
   （主控型・莓果／明辨型・抹茶／優越型・布丁／舒適型・柑橘／和諧型・巧克力）。
3. 裝飾蛋糕：選擇蛋糕胚、淋醬、水果、寶石、花朵、蝴蝶結、餅乾&糖果、奶油
   等裝飾；可用「上一步」「重來」。製作期間畫面上方會出現彈幕建議。
4. 上架：蛋糕滑進櫥窗。
5. 回顧（畫面一～七）：依實際操作記錄顯示
   ・製作總時長
   ・操作時長與空白時長（兩次操作間停頓 1 秒以上即計入空白）
   ・各類裝飾品使用比例
   ・按「上一步」的次數
   ・受到彈幕影響的紀錄與裝飾回放
   ・總回顧收據（顏色依人格類型變化）
6. 下載：在總回顧按「下載」會出現 QR Code，用手機掃描即可開啟並儲存收據圖片。
7. 總回顧畫面停留 60 秒後自動回到開場，也可按右下角「重新開始」。
